エビデンス格付け：対象外

★は、成分・検査・生活習慣ごとの根拠の強さを示す当サイトの格付けです（判断基準）。この記事は制度・指標・事例の解説、または根拠の強さが異なる複数の方法の整理のため、★を付けていません。

情報の確度：本記事は、認定制度の申請手続き・要件（経済産業省などの公式情報）の解説であり、手続き情報としての確度は高いものです。一方、健康経営そのものの業績への効果は、因果が確立しておらず、別の記事で扱っています。日程・要件は年度によって変わるため、公式サイトにて最新情報をご確認ください。

要点（現時点の研究状況）

  • ●健康経営優良法人2027の申請受付は2026年8月17日〜10月9日（大規模法人部門）・10月16日（中小規模法人部門）で、すでに終了しています。内定は2027年2月下旬ごろ、認定の発表は2027年3月の予定です（ACTION!健康経営、2026年11月15日確認）。申請書には申請日までに実施した取り組みだけを記載できるため、取得を目指す場合は申請期間より前に施策を実施しておく必要があります（次回の日程は公式サイトでご確認ください）。
  • ●部門は2つあります。大規模法人部門（上位法人＝ホワイト500）は、「健康経営度調査」（経済産業省と日本経済新聞社が連携して実施）への回答が必須であり、中小規模法人部門（上位500法人＝ブライト500）は、保険者等の「健康宣言事業」への参加と認定申請書の提出が起点です。まず、自社がどちらの部門に該当するかを確認してください。
  • ●認定は、「健康経営で成果が出ているか」ではなく、「健康経営に取り組む体制と施策があるか」を要件で評価する制度です。健康経営優良法人2026では、大規模法人部門で3,765法人、中小規模法人部門で23,085法人が認定されています（経済産業省）。

健康経営優良法人とは（制度の位置づけ）

健康経営優良法人は、特に優良な健康経営を実践している法人を日本健康会議が認定する顕彰制度で、制度の設計は経済産業省が行っています。大規模法人部門と中小規模法人部門の2つがあり、大規模法人部門の上位法人には「ホワイト500」、中小規模法人部門の上位500法人には「ブライト500」、501〜1500位の法人には「ネクストブライト1000」の冠が付きます。認定期間は約1年（健康経営優良法人2026は2026年3月9日〜2027年3月31日）で、認定を続けるには毎年申請します。認定されるとロゴマークを使用でき、自治体や金融機関によるインセンティブを受けられる場合があります（経済産業省）。

STEP0：自社の部門を確認する

申請の経路と必須の調査が部門によって異なるため、最初に部門を確認します。会社の場合、大規模法人部門は従業員数が卸売業・サービス業で101人以上、小売業で51人以上、製造業その他で301人以上の法人です。中小規模法人部門は従業員数がそれ未満、または資本金・出資金額が一定以下（卸売業1億円以下・小売業とサービス業5,000万円以下・製造業その他3億円以下）の法人です。従業員数は大規模、資本金は中小規模に当たる場合は、どちらか一方の部門に申請できます（健康経営優良法人2027 申請区分）。大規模は「健康経営度調査」への回答が必須、中小規模は保険者（協会けんぽ・健康保険組合等）の「健康宣言事業」への参加＋認定申請書が起点になります。保険者が健康宣言事業を実施していない場合は、自治体の健康宣言事業への参加か自社独自の健康宣言で代替できます。区分の定義は年度ごとに公式資料でご確認ください。

STEP1：申請スケジュールを把握する（2027年版の日程）

健康経営優良法人2027の日程は次のとおりです（ACTION!健康経営、2026年11月15日確認）。

  • 申請期間：2026年8月17日〜10月9日17時（大規模法人部門）／10月16日17時（中小規模法人部門）
  • 請求書の送付：2026年11月上旬ごろ（申請料の振込期限は12月31日）
  • 内定：2027年2月下旬ごろ
  • 認定の発表：2027年3月
  • 評価結果の送付（中小規模法人部門）：2027年4月中旬ごろ

重要なのは、申請書に記載できるのは申請日までに実施した取り組みだけという点です。2027年版の中小規模法人部門では、2025年4月1日から申請日までに実施した内容が対象で、申請日以降に実施する予定の取り組みは実績として記載できません。申請期間に入ってから準備を始めても、記載できる実績が足りなくなるおそれがあります。次回の日程・様式はACTION!健康経営および経済産業省の公式ページでご確認ください。

STEP2：認定要件の全体像を知る

認定要件は大きく5つの項目で構成されます（健康経営優良法人2027 認定要件）。

  1. 経営理念・方針（健康経営の方針の明文化・トップの関与）
  2. 組織体制（推進担当・責任者の設置、保険者との連携）
  3. 制度・施策の実行（健診受診・受診勧奨、生活習慣（運動/食/禁煙）、メンタルヘルス、長時間労働対策 など）
  4. 評価・改善（取り組みの効果検証・改善のサイクル）
  5. 法令遵守・リスクマネジメント（定期健診の実施、50人以上の事業場でのストレスチェックの実施、労働基準法・労働安全衛生法違反による送検がないこと等の自主申告）

大規模は「健康経営度調査票」、中小規模は「認定申請書」に、これらの取り組み状況を記入して専用サイトから申請します。必須項目と選択項目があり、必須項目を満たしつつ、選択項目を一定数満たすことが基本的な構造です。2027年版の選択項目は、大規模法人部門が16項目のうち14項目以上（ホワイト500は17項目のうち14項目以上）、中小規模法人部門が分野ごとに定められた数以上です（詳細は公式の認定要件でご確認ください）。

STEP3：取得ロードマップ（前年〜認定までの月別アクション）

中小規模法人を想定した標準的な進め方です（大規模は健康経営度調査票の記入・提出が必要です）。

  • 前年 春〜初夏：①保険者の「健康宣言」に参加 ②推進体制（担当者・責任者・できれば役員）を決める
  • 前年 夏：現状把握（健診受診率・ストレスチェック実施・労働時間・喫煙率など）を数値で棚卸しし、不足している施策を洗い出す
  • 前年 夏〜秋：洗い出した施策を実際に実行（受診勧奨、運動・食・禁煙の取り組み、メンタル対策、長時間労働の是正 など）。同時に調査票・調査へ回答
  • 前年 8〜10月：申請期間中に、事務局から案内される専用サイトへ認定申請書をアップロード（2027年版は2026年8月17日〜10月16日。初めて申請する場合は事前に新規ID登録が必要）
  • 認定年 2月下旬ごろ：内定
  • 認定年 3月：認定発表

このように、「宣言→体制→現状把握→施策実行→回答・申請」の順で、申請日までに実施した取り組みを積み上げることが基本です。

注意点と陥りやすい誤り

  • 「効果（業績の向上）が出ていないと取得できない」という誤解：評価されるのは取り組みの体制と施策であり、業績や健康指標の結果そのものではありません。まず、体制づくりに取り組んでください。
  • 日程・様式は毎年変わる：前年の情報のみに頼らず、その年の公式の要件を確認してください。
  • 健康宣言事業への参加が先に必要：中小規模法人部門は、申請前に保険者の健康宣言事業への参加が必要です。加入している協会けんぽ・健保組合の手続きを、早めに確認してください。
  • 直前の着手では実績が足りない：申請書に記載できるのは申請日までに実施した取り組みだけで、申請日以降の予定は記載できません。

健康経営の効果の考え方（中立の立場からの注記）

最後に、重要な点を記載します。認定は「取り組みの評価」であり、業績の向上を保証するものではありません。「健康経営に取り組む企業は業績が良い」という相関の指摘はありますが、因果（健康経営が業績を上げた）は未確立で、健康経営銘柄全体の株価はTOPIX並みかやや下回る期間が多いという証券会社の分析もあります（出典は日本企業の業界別 健康経営事例に掲載）。認定は、「人的資本への投資姿勢を社内外に示す手段」と捉えることが適切です。効果測定の考え方や数字の読み方については、プレゼンティーイズムとアブセンティーイズム、測定尺度の比較、健康経営とはの記事もあわせてご覧ください。認定を受けた企業が、実際にどのような数値をどのように開示しているかは、日本企業の業界別 健康経営事例で確認できます。

よくある質問

健康経営優良法人2027の申請はいつからですか？

健康経営優良法人2027の申請期間は2026年8月17日〜10月9日（大規模法人部門）・10月16日（中小規模法人部門）で、すでに終了しています。内定は2027年2月下旬ごろ、認定の発表は2027年3月の予定です（ACTION!健康経営、2026年11月15日確認）。申請書には申請日までに実施した取り組みだけを記載できるため、次回の申請を目指す場合は、施策を早めに実施してください。次回の日程は公式サイトでご確認ください。

中小企業でも取れますか？費用はかかりますか？

取得できます。中小規模法人部門があり、保険者（協会けんぽ・健康保険組合等）の健康宣言事業への参加が起点です。2027年版の認定申請料は、中小規模法人部門が1件15,000円（税込16,500円）、大規模法人部門が1件80,000円（税込88,000円）です（大規模でグループ会社と合算して申請する場合は1社ごとに15,000円〔税込16,500円〕を加算）。このほか、施策の実施には費用や工数がかかります。

認定されるとどんなメリットがありますか？

認定されると「健康経営優良法人」のロゴマークを使用できます。また、国や公共団体等の補助金申請時の加点や、融資での優遇利率など、認定法人を対象にしたインセンティブがあります（ACTION!健康経営「国の取り組み」）。内容は制度・自治体・金融機関によって異なり、変わることがあるため、各機関にご確認ください。また、認定自体が業績の向上を保証するものではありません。

健康経営に取り組めば業績は上がりますか？

「健康経営に取り組む企業は業績が良い」という相関の指摘はありますが、因果（健康経営が業績を上げたかどうか）は確立していません。認定は取り組み体制の評価であり、効果を保証するものではありません。効果測定の考え方については、プレゼンティーイズムの記事もご覧ください。
